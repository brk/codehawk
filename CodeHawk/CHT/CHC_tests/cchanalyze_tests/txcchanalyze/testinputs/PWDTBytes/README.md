Parser-only LP64 byte-region controls; unsafe C is analyzed, never run.

require_bytes and require_raw_bytes require five initialized bytes from a
uint32_t pointer. Four-byte objects must fail the exact byte bounds; two-word
objects pass. Explicit IndexSize(2) keeps its typed-element meaning.

The remaining functions mirror the LC validator proof boundary: scalar, union,
structure-field and last-of-176 local sources work; partial initialization,
siblings, opaque overwrites, allocator/table pointer outputs and release cannot
supply missing source bytes or lifetime. A readonly frame remains conditional.
The reduced Entry is not LC_WDTEntry_t and does not redefine production sizes.
memset aggregate and callback-pointer controls record demonstrated limitations;
this repair changes only generated byte bounds, not region initialization.
